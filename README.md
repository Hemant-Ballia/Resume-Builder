# 🚀 AI-Powered MERN Resume Builder

A modern, full-stack SaaS platform that empowers users to create professional, ATS-friendly resumes in minutes using AI-driven content suggestions and dynamic templates.

## 🌐 Live Demo
**Frontend:** [Live Link](https://resume-client-hemant.vercel.app)  
**Backend API:** [API Link](https://resume-server-five.vercel.app)

---

## ✨ Features
- **AI Content Enhancement:** Integrated Gemini AI API to automatically refine and professionalize job descriptions and summaries.
- **Real-Time Preview:** Dynamic live preview system built with React to see changes instantly as you type.
- **Secure Authentication:** Robust user login and signup system using **JWT** and **Bcrypt** for password hashing.
- **Responsive UI:** Fully mobile-friendly and sleek interface designed with **Tailwind CSS**.
- **Dynamic Templates:** Multiple professional layouts to suit different industry standards.
- **Data Persistence:** Securely save and manage multiple resumes in a cloud-hosted MongoDB database.

---

## 🛠️ Tech Stack

### Frontend
- **React.js** (Vite)
- **Tailwind CSS** (Styling)
- **Lucide React** (Icons)
- **Axios** (API Calls)

### Backend
- **Node.js** & **Express.js**
- **MongoDB** (Mongoose ODM)
- **JSON Web Tokens (JWT)** (Auth)
- **Bcrypt.js** (Security)

### DevOps / Tools
- **Vercel** (Frontend & Backend Hosting)
- **Git/GitHub** (Version Control)
- **Postman** (API Testing)
